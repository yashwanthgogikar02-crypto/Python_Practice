# Python Practice: Object-Oriented Programming (OOP)

This repository contains practical implementations of core Object-Oriented Programming (OOP) concepts in Python. It serves as a workspace for mastering foundational software engineering patterns.

## 📂 Featured Programs
The main `sol.ipynb` notebook contains two distinct OOP programs:

1. **Geometric Shape Inheritance Model**
   - Implements a base `Shape` class and a derived `Circle` class.
   - Practices **inheritance** and method overriding (`def area(self)`).
   - Dynamically calculates the area of a circle using radius parameters.

2. **Core OOP Logic Practice**
   - Demonstrates the use of constructors (`def __init__`), instance attributes, and custom class methods.
   - Validates class behaviors with real-world object instantiations and executions.

## 🚀 Skills Demonstrated
- **Encapsulation & Inheritance:** Designing clean parent-child class structures.
- **Problem Solving:** Translating algorithmic rules into neat, clean Python classes.
- **Interactive Workspaces:** Developing and debugging code inside Jupyter Notebooks.
